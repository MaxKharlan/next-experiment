    Inspect local training labels

    Paste reference and observed unpadded token rows. The reference must use correct answer-only labels. This checks prompt loss, EOS masking and label alignment. It does not train a model or confirm a cause.

    On this static site, pasted data stays in your browser. Supply unpadded rows: reference -100 positions must be prompt tokens only. Position 0 is excluded from causal loss. The reference is yours; this audit cannot judge its semantic correctness or prove a cause of model behavior.

    Limits: 1–1024 rows per side, 32768 positions per row, 131072 positions across both sides. Token IDs are nonnegative integers; labels may also be -100. Both sides must describe identical token sequences. Optional eos_token_id must be a nonnegative integer or null.
